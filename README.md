# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/c19656dd-a327-4423-bba6-2908681c5c6b

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set `DEEPSEEK_API_KEY` in `.env` or `.env.local` (see [.env.example](.env.example))
3. Run the app:
   `npm run dev`
